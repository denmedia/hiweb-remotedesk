# hiWeb RemoteDesk

**Удалённый рабочий стол Windows (и Ubuntu) на планшете — с полноценным тачпадом, жестами и родной
клавиатурой чехла.**

Приложение написано для Samsung Galaxy Tab S9 Ultra с чехлом-клавиатурой: планшет превращается в тонкий
клиент к вашему ПК, а чехол работает как настоящий тачпад ноутбука. Под капотом — собственный клиент RDP
на Kotlin, без FreeRDP и сторонних библиотек протокола.

---

## Что умеет

### Рабочий стол без компромиссов
- **RDP с расширенной безопасностью**: TLS, NLA (CredSSP/NTLM), закрепление сертификата по SHA-256.
- **Графика двумя путями**: классические битмап-обновления для Windows и конвейер RDPEGFX
  (RemoteFX Progressive) — без него не получить картинку от GNOME Remote Desktop в Ubuntu.
- **Сеанс продолжается в свёрнутом приложении**: служба переднего плана не даёт Android заморозить
  соединение.
- **Поворот экрана меняет размер рабочего стола**: в книжной ориентации стол 1920 по высоте, без выхода
  из сеанса (Windows сохраняет сеанс даже при переподключении).
- **Масштаб интерфейса Windows** (100–300 %) и **глубина цвета** (16/24/32 бита) — на каждый ПК отдельно.

### Тачпад чехла как в ноутбуке
- Курсор с ускорением, левая/правая/средняя кнопка, физический щелчок.
- Прокрутка двумя пальцами в стиле macOS с **инерцией** (сила прокрутки и сила инерции настраиваются
  на каждый ПК).
- Щипок — масштаб (Ctrl + колесо), быстрый свайп — назад/вперёд в браузере.
- Свайпы тремя-четырьмя пальцами: обзор окон, рабочий стол, переключение виртуальных рабочих столов.
- Перетаскивание «лежащий палец + второй палец», как на трекпаде Mac.
- Калибровка осей — тачпад в чехле установлен боком относительно экрана.

### Жесты на самом экране
Три-пять пальцев переводятся в сочетания клавиш Windows или GNOME: отмена/повтор, копировать/вставить/вырезать,
Alt+Tab, «домой», переключатель приложений.

### Клавиатура и мышь
- Физическая клавиатура чехла и Bluetooth-клавиатура работают напрямую.
- Служба специальных возможностей доставляет на ПК **Win, Alt+Tab и другие** сочетания, которые Android
  иначе забирает себе. Работает только пока открыт экран сеанса.
- Автоповтор клавиш как в Windows: пауза, затем частые повторы.
- Экранная клавиатура Windows появляется сама, когда вы касаетесь поля ввода, и её касания считаются
  набором текста, а не жестами (см. HiWeb Agent).

### Файлы, буфер и звук
- **Текст через буфер обмена** в обе стороны.
- **Файлы через буфер обмена**: скопировали файл на планшете — вставили на ПК (Ctrl+V), и наоборот;
  файлы с ПК сохраняются в `Загрузки/RemoteDesk` с индикатором прогресса.
- **Общий диск**: папка планшета видна в Windows как сетевой диск `\\tsclient\Имя`, в том числе
  «только для чтения». Диск можно подключить прямо во время сеанса.
- **Звук ПК** воспроизводится на планшете (канал rdpsnd).

### Один экран — все компьютеры
- Карточки ПК с **живым превью экрана**, поиском, фильтрами («онлайн», «оффлайн», по ОС) и сортировкой.
- **Поиск ПК в сети** одной кнопкой: скан подсети и определение ОС по баннеру SSH и ответу RDP — без
  ввода учётных данных.
- **Состояние ПК по-человечески**: «онлайн», «за ПК работают», «экран заблокирован», «вход не выполнен»,
  «сон», «гибернация», «перезагружается», «выключен».
- **Пробуждение по сети (Wake-on-LAN)**: подключение к спящему ПК сначала будит его, затем ждёт порт RDP.

### Питание ПК
Три пути — какой доступен, такой и используется:
1. **HiWeb Agent** (ПК на связи по локальной сети): выключить, перезагрузить, сон, гибернация — с учётом
   реально поддерживаемых ПК режимов.
2. **SSH для Ubuntu**: команда уходит без открытия рабочего стола.
3. **Через сеанс RDP**: приложение входит, открывает штатное меню питания Windows и отключается —
   на ПК ничего не устанавливается.

### HiWeb Agent для Windows (необязательно, но именно он делает связку «планшет + ПК» целой)
- **Установка из приложения**: exe доставляется на ПК как временный диск через уже открытый сеанс
  и запускается в окне «Выполнить» — без скачивания, флешек и почты.
- **«Переключиться на Планшет» из меню в трее**: ПК сам зовёт планшет, сеанс открывается, мониторы гаснут.
- **Уведомления Windows на планшете**, пока приложение свёрнуто (с фильтрами от Phone Link и своих).
- **Сенсорная клавиатура Windows по требованию**: приложение сообщает агенту, есть ли у планшета
  клавиатура; без неё агент показывает TabTip при щелчке в поле ввода.
- **Превью ПК без сеанса**: агент раз в 15 минут присылает зашифрованный снимок экрана.
- **Иконка в трее**: силуэт ноутбука под тему панели задач с батарейкой планшета.

## Начало работы

1. Установите APK на планшет (Android 13 и новее).
2. На ПК включите удалённый рабочий стол: «Параметры → Система → Удалённый рабочий стол»
   или скрипт из репозитория `tools/enable-rdp.ps1` (его нужно скопировать на ПК и запустить
   от имени администратора).
3. В приложении нажмите **«Поиск»** и добавьте найденный ПК — или введите адрес вручную.
4. Для сочетаний Win / Alt+Tab включите службу «RemoteDesk: передача клавиш» в специальных возможностях.
5. По желанию установите **HiWeb Agent**: кнопка «Установить агент» в меню сеанса.

Тачпад при первом запуске попросит один раз провести пальцем по осям — так приложение узнаёт, как
повёрнут тачпад в чехле.

### Сборка

JDK нет в PATH — сначала указать:

```powershell
$env:JAVA_HOME = "D:\Program Files\Android\Android Studio\jbr"
./gradlew.bat --console=plain -q :app:testDebugUnitTest :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Отладочная сборка ставится на планшет по беспроводному
adb: `adb install -r -t app-debug.apk`.

Агент (только C# 5):

```powershell
windows-agent\build.cmd
```

Скрипт кладёт `HiWebAgent.exe` и `version.txt` в `app/src/main/assets/agent/`. Чтобы приложение предложило
обновление агента, увеличьте `windows-agent/VERSION`, пересоберите агент, затем APK.

### Протокол и порты

| Канал | Порт / транспорт | Назначение |
|---|---|---|
| RDP (Windows) | TCP 3389, TLS + NLA | сеанс, графика, ввод |
| RDP (Ubuntu) | TCP 3390 | GNOME Remote Desktop (требует RDPEGFX) |
| Статические каналы | внутри RDP | `cliprdr` буфер/файлы, `rdpdr` общий диск, `rdpsnd` звук |
| Динамические каналы | внутри RDP (drdynvc) | `HiWeb::Agent`, курсор, `RDPEDISP` смена размера стола |
| Агент ↔ планшет | TCP 47853, JSON + HMAC | состояние ПК, питание, превью, «switch» |
| Приглашение планшета | UDP 47853 | подписанная команда «Переключиться на Планшет» |
| Wake-on-LAN | UDP 9 и 7 | пробуждение спящего ПК (широковещательно) |

Раскладки PDU взяты из исходников FreeRDP; байтовые структуры — `rdp/Bytes.kt`.
Сообщения каналов режутся на фрагменты по 1600 байт.

### Формат устройства

`Device`: `id`, `name`, `host`, `port`, `os` (`WINDOWS`/`UBUNTU`), `username` (`ДОМЕН\имя`), пароль,
`certSha256` (закреплённый сертификат), `useNla`, `scalePercent`, `scrollLevel`/`inertiaLevel`,
`fileTransfer`, `drive*` (общий диск), `colorDepth`, `wakeMac`.
Хранится в SharedPreferences (`devices`), пароли — только в зашифрованном виде.

### Безопасность

- Пароли — AES-GCM ключом из Android Keystore (`SecretBox`), без пароля в открытом виде на диске.
- Сертификат ПК закрепляется при первом подключении; смена сертификата отменяет подключение.
- Ключ SSH-хоста запоминается при первом входе и сверяется до отправки пароля.
- Команды по локальной сети подписываются HMAC-SHA256; снимки экрана — AES-256-CBC.
- Вход в «Переключиться на Планшет» защищён подписью, окном часов (±5 мин) и однократностью `nonce`.

### Тесты

`app/src/test/` — JVM-тесты на протоколы и чистую логику: разбор PDU cliprdr/rdpdr/rdpsnd/дисплей-канал,
декодер курсора, жесты тачпада и тачскрина, инерция прокрутки, детектор ОС, крипто, статусы ПК, SecureLines,
сравнение версий агента. Инструментальные тесты (`connectedAndroidTest`) переустанавливают приложение
и удаляют сохранённые ПК — на рабочем планшете их не запускать.

### Ограничения

- Клиент рассчитан на Windows и Ubuntu с GNOME Remote Desktop; другие RDP-серверы не гарантируются.
- Сенсорная клавиатура Windows и уведомления требуют HiWeb Agent; без него сеанс полностью работоспособен.
- Экранная клавиатура планшета в сеансе не показывается — ввод идёт с физической клавиатуры и тачпада.
